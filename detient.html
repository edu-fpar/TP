Table d'association detient

Relation plusieurs-à-plusieurs entre les copropriétaires et les appartements du syndic.

SQL Modèle relationnel N–N

À quoi sert cette table ?

Un copropriétaire peut posséder plusieurs appartements, et un appartement peut appartenir à plusieurs copropriétaires. Cette relation plusieurs-à-plusieurs ne peut pas être représentée directement dans une seule table : on utilise donc une table d'association (aussi appelée table de jointure ou table pivot).

Clé primaire composite

(code_coproprietaire, code_appartement)
Le couple identifie de façon unique une détention.

Deux clés étrangères

code_coproprietaire → coproprietaire
code_appartement → appartement

Attribut de relation

quote_part : pourcentage de détention (0–100). La somme par appartement doit valoir 100 %.

Exercices

Écrire la requête SQL qui affiche toutes les lignes de la table detient, triées par code d'appartement puis code de copropriétaire.

SELECT *
FROM detient
ORDER BY code_appartement, code_coproprietaire;

Lister les copropriétaires qui possèdent plus d'un appartement, avec le nombre d'appartements détenus.

SELECT c.code_coproprietaire, c.prenom, c.nom,
       COUNT(*) AS nb_appartements
FROM coproprietaire c
JOIN detient d ON d.code_coproprietaire = c.code_coproprietaire
GROUP BY c.code_coproprietaire, c.prenom, c.nom
HAVING COUNT(*) > 1
ORDER BY nb_appartements DESC;

Afficher tous les copropriétaires de l'appartement APT003, avec leur quote-part.

SELECT c.prenom, c.nom, d.quote_part
FROM coproprietaire c
JOIN detient d ON d.code_coproprietaire = c.code_coproprietaire
WHERE d.code_appartement = 'APT003'
ORDER BY d.quote_part DESC;

Vérifier que pour chaque appartement, la somme des quote-parts vaut bien 100 %.

SELECT code_appartement, SUM(quote_part) AS total
FROM detient
GROUP BY code_appartement
HAVING SUM(quote_part) <> 100;

Aucune ligne ne doit être retournée si toutes les sommes valent 100.
