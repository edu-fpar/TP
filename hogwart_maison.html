Table maison

Les quatre maisons de Poudlard, extraites du fichier hogwartHierarchic.json.

SQL Modèle relationnel 4 lignes

À quoi sert cette table ?

Dans le fichier JSON, les étudiants sont imbriqués sous les maisons (Gryffindor, Slytherin, Hufflepuff, Ravenclaw). En base de données relationnelle, on normalise : on isole les maisons dans une table dédiée, et on les référencera depuis la table etudiant.

Identifiant

Chaque maison possède un identifiant unique (id), qui sera référencé depuis d'autres tables.

Nom

Le nom de la maison, tel qu'il apparaît dans le JSON (clé de l'objet etudiants).

Utilisation

Référencée par etudiant.maison et professeur.responsable.

Exercices

Écrire la requête SQL qui affiche toutes les lignes de la table maison, triées par identifiant.

SELECT *
FROM maison
ORDER BY id;

Afficher la ligne correspondant à la maison Ravenclaw.

SELECT *
FROM maison
WHERE nom = 'Ravenclaw';

À partir des tables maison et etudiant, compter le nombre d'étudiants par maison.

SELECT m.id, m.nom, COUNT(e.id) AS nb_etudiants
FROM maison m
LEFT JOIN etudiant e ON e.maison = m.id
GROUP BY m.id, m.nom
ORDER BY m.id;

Afficher, pour chaque maison, le professeur qui en est responsable (ou aucune ligne si personne).

SELECT m.id, m.nom, p.prenom, p.nom
FROM maison m
LEFT JOIN professeur p ON p.responsable = m.id
ORDER BY m.id;

Attention : dans le JSON, Sybill Trelawney a responsable = null. Un LEFT JOIN côté maison permet de voir les maisons sans responsable.
